# Problem 11 – Recursive Reasoning Framework

This repository implements a shared recursive reasoning and visualization framework
for Problem 11 (a–e).

## Problems Covered
- (a) Cards / Coins in the Dark
- (b) Ten Pirates and Gold
- (c) Handshake Problem
- (d) Airline Seats
- (e) Birthday Problem

## Project Structure
- `engine/` – shared recursion, animation, and metrics logic
- `problems/` – individual problem definitions
- `algorithms/` – brute-force and optimized strategies
- `results/` – experiment outputs and comparisons
